# Input data

Place one de-identified research case in each immediate child folder:

```text
input/
├── HCM0001/
│   └── *.dcm
└── HCM0002/
    └── *.dcm
```

Each case folder must contain exactly one complete conventional single-frame SAX
cine series. Do not place patient names, medical-record numbers, other DICOM
series, or derived outputs here.
