# CorSeg model weight

This directory intentionally does not contain a pretrained model checkpoint.

Download the MedNeXt-L CorSeg-CineSAX checkpoint from the official project:

- <https://github.com/RunhaoXu2003/CorSeg>
- <https://pan.baidu.com/s/1BM9viKgzGoECovzjxbMgtg?pwd=4396>

The default expected path is:

```text
weights/ModelWeight-CorSeg-CineSAX_MedNextL.pth
```

If the official archive uses a different filename, pass the verified checkpoint
with `--weight`. Do not download `.pth` files from untrusted mirrors.
